# Adaptación de Modelos de Re-Identificación Visual de Perros y Gatos en la Región de O'Higgins

## 📌 Descripción del Proyecto
Este proyecto evalúa y estudia la aplicación de técnicas de visión por computador y modelos de Re-Identificación (Re-ID) biométrica en perros y gatos, con el objetivo de adaptar estas tecnologías para apoyar la búsqueda y recuperación de mascotas extraviadas en el contexto de la Región de O'Higgins, Chile.

## 🎯 Objetivos
1. **Evaluar** la efectividad de modelos de Re-ID preentrenados (e.g., basados en datasets como PetFace) en la identificación individual de perros y gatos.
2. **Estudiar la adaptación** de estos modelos frente a imágenes no controladas en el entorno local (Región de O'Higgins).
3. **Analizar la factibilidad** de integrar estas métricas como complemento sin contacto a los registros existentes (como el microchip o el Registro Nacional de Tenencia Responsable).

## 🗂️ Estructura del Repositorio
- `docs/`: Documentación, marcos teóricos y entregables del proyecto.
- `notebooks/`: Experimentos y análisis exploratorio de datos.
- `src/`: Módulos de código Python.
